- publish repeatable CI results across Linux, macOS, and Windows
- tighten packaging and installation ergonomics
- expand examples for host integration and embedded watchdog flows

- improve binding coverage and release packaging
- document provider compatibility expectations in more detail
- add ABI compatibility guidance for downstream integrators

## Guardrails

- keep the public API small
- keep cryptography delegated to established providers
- avoid product-specific runtime logic in this repository
